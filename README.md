# Taskhive
A freelance marketplace web application built with Django and PostgreSQL. Users can register, create tasks, place bids, manage categories, and track project status through an admin dashboard.
# TaskHive

TaskHive is a freelance marketplace web application developed using Django and PostgreSQL.

## Features

- User Authentication
- Task Management
- Categories
- Bidding System
- Search & Filter
- Admin Dashboard
- PostgreSQL Database

## Technologies

- Python
- Django
- PostgreSQL
- HTML
- CSS
- Bootstrap
